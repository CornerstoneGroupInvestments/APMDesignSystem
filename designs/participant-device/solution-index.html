ES Participant Kiosk Solution

A physical Dell device in an APM Employment Services site, for participant use. Windows 11 Enterprise under multi-app Assigned Access, signing itself in to a local account no person holds a credential for. Every artefact is listed below by kind, so a resource can be found, cited or lifted out without reading the whole design.

Lifting the solution out

Standalone bundle

A complete, self-contained copy sits at exports/es-participant-kiosk/: 80 files, its own CLAUDE.md, the diagram kit, the pipeline and only the policy sources this solution cites.

Folder depth mirrors this project so figures.html keeps resolving ../../styles.css.

What stays behind

The wider policy corpus, ESLZ reference material, the programme plan and the other four SOE use cases stay here. The bundle carries only what the Kiosk cites, which is what makes it separable.

Naming, as built

Most Kiosk Intune objects are CDG-W11-*, but four classes are not, and all four are recorded as built rather than corrected. The Autopilot deployment profile is CDG W11 Autopilot SelfDeploying - spaces, no hyphens - and CA-107's device filter matches that string literally, so it must not be renamed while CA-107 is enforced. The App Control base and supplemental policies carry the estate APM-WIN-SEC- prefix and the exclusion policy APM-W11-SEC-. The profile-deletion and certificate profiles carry CDG-WIN-. The SCEP and Wi-Fi profiles carry the -D- environment suffix on a production fleet.
