H1 |2. Solution Summary
H2 |2.1 What is deployed
P |A physical Dell device in an APM Employment Services site, for participant use. It runs Windows 11 Enterprise under multi-app Assigned Access and signs itself in to a local account that no person holds a credential for. There is no participant identity, no credential to issue and nothing displayed for a participant to type.
P |The device is Entra ID joined and managed entirely by Intune. It is provisioned by Windows Autopilot in self-deploying mode on top of an APM image installed at the build facility. Applications are installed locally: Microsoft Edge, LibreOffice Writer, Calc and Impress, and File Explorer scoped to the Downloads folder and removable drives. Microsoft 365 is blocked from the device at three independent layers.
P |Every session ends at a restart, and the restart destroys the session. The device restarts after ten minutes without input, and the purge runs at logon and at logoff.

GD |All four screen-saver values are REG_SZ. Winlogon reads them as strings, so a REG_DWORD is a silent no-op: the value appears set, and the screen saver never starts. Detection reads the value type through reg.exe rather than trusting the data alone.
P |Two of the seven rows above are the ones a reviewer should check first. Without Success auditing on that subcategory no 4800 event is ever written, so nothing in this pack fires and the device never restarts. With a display timeout other than 0 the screen blanks before the screen saver is due, which looks to a participant like a device that has failed.
P |Remediation is ordered so that a partial run cannot present as a working device: it clears the version marker first, resolves the session account from the profile directory on disk and stops outright if it cannot, and refuses to touch the scheduled task until it has an account name to filter on.
