Standard User SOE on Azure Virtual Desktop

The staff desktop delivered as a service. Windows 11 Enterprise multi-session on a pooled AVD host pool, orchestrated by Nerdio, reached through the Windows App from a managed laptop or an unmanaged personal device. Every artefact is listed below by kind, so a resource can be found, cited or lifted out without reading the whole design.

PROGRAMMEStandard Operating Environment
USE CASEP2 of 5
REGIONAustralia East
One SOE, two channels. The session host is assigned the same 11 Intune policy objects as the Windows 11 thick client, not a copy of them. Where the channels diverge it is named, and there are four: device join type (thick clients hybrid joined and ADFS-federated, session hosts Entra ID joined), SOE update by golden image replacement rather than in-place patching, the five varied controls in Detail 7, and the multi-session application requirements in Detail 5.4. Australia East only.

Lifting the solution out

Standalone bundle

A complete, self-contained copy sits at exports/standard-user-avd/: its own CLAUDE.md, the diagram kit, the pipeline and only the policy and reference sources this solution cites.

Folder depth mirrors this project so figures.html keeps resolving ../../styles.css.

What stays behind

ESLZ corpus Parts 2 and 4, the Employment Services hardening standard, the programme plan and the other four SOE use cases stay here. The bundle carries only what this design cites.

Separable by design

Nothing in the session host path needs on-premises Active Directory or ADFS: no domain membership, no Group Policy, no domain controller reachability. The one residual link is Entra Kerberos authenticating a hybrid identity to the profile store, which is a user identity link, not a device one (DR-019, Detail 5.4.8).

An on-premises file server back end for the mapped drive is the one option that would break it.

Licensing, settled

No AVD-specific licence is required. The Windows 11 Enterprise E5 user subscription licence inside Microsoft 365 E5 carries both the AVD user access right and the multi-session use right. Confirmed with SoftwareOne (A-01).
