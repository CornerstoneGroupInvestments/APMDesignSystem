H1 |4. Solution Design
H2 |4.1 Solution Overview
P |Users reach a pooled Windows 11 Enterprise multi-session desktop through the Windows App. Session hosts are built from a golden image in the Compute Gallery, provisioned and scaled by Nerdio, Entra ID joined and Intune managed, and hold each user's profile in an FSLogix container on Azure Files Premium. Web traffic from each user session is tunnelled by Zscaler Client Connector for VDI to a Zscaler Cloud Connector pair in the spoke. All spoke egress is forced to the hub firewall. The architecture is in DDD 4 and DDD 5.
