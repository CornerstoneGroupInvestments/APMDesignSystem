Overview
Purpose of this Document
This document provides a high-level naming schema for managing Intune policies, configurations, remediation and profiles to standardise and support operations within APM’s Intune environment. It provides a naming schema to be used as reference information for those managing the APM Intune tenancy.
Naming Schema Overview
This naming schema is intended to provide a standard naming format for all Intune specific configuration items.
This document is intended for the technical staff within ITS, including Strategy, Architecture and Security and Technology Operations, who will reference this document when managing and maintaining the Intune environment.
This is intended to be a working document, with updates approved by APM ITS management.

Version
The version format is a simplified release numbering.
<Major Version Number>  .  <Minor Version Number>
Eg:  1.0
Major versions are for a core functional change to the policy, significant minor changes to the policy, or the change is expected to impact end user experiences.
Minor versions are for minimal changes to the policy, where these are not expected to have any impact on end user experience and do not change the core functions of the policy.
Version may be replaced with another qualifying identifier, if this makes sense to do so.
An example would be group names in Intune, for instance this would be a potential release ring name for Windows Update for all Window devices.
APM-WIN-UPD-Windows Update-P-Ring 1
