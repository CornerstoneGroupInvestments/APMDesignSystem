Both endpoint contexts reach the same session host pool and the same SOE. The difference is what may leave the session: clipboard and drive redirection are open on the managed path and closed on the unmanaged path (Figure 4). No APM data is written to either endpoint. Egress from the spoke is forced to the hub firewall by route table, so the spoke holds no public IP address and no NAT Gateway.

Conditional Access is evaluated twice: once for the client authenticating to the Azure Virtual Desktop application, and once for the session's own sign-in to the host. The endpoint trust decision is therefore made before a session exists. No step opens an inbound port into the spoke; both the endpoint and the session host connect outbound to the Microsoft-managed gateway. Step 6 is a hard gate, which is what prevents a user's data being written to a host that will later be replaced.

Access control model - managed and unmanaged endpoint paths
MANAGED ENDPOINT PATH

Corporate laptop

Entra-joined, Intune-managed, evaluated compliant by the staff compliance policy.

Conditional Access

MFA required. The compliant-device gate is satisfied, so direct access is also permitted.

Managed application group

Clipboard and drive redirection enabled.

UNMANAGED ENDPOINT PATH

Personal device

Not compliant and not Entra-joined. Runs the Windows App and nothing else.

Conditional Access

MFA required for AVD. Every other Microsoft 365 application is blocked outright.

Unmanaged application group

Clipboard and drive redirection disabled.

One AVD host pool, two desktop application groups

Both groups publish the same desktop from the same hosts. They differ only in their RDP device-redirection properties, because AVD does not expose those properties as a per-sign-in condition.

Session host

Hardened to the same standard as the laptop, Intune-managed, compliant, with App Control in enforcement. Camera and microphone redirection are permitted on both paths, because Teams requires them and neither carries a file out of the session.

Direct Microsoft 365 retained

A compliant managed device already holds APM data legitimately, so closing redirection there would remove a working practice with no security gain.

Direct Microsoft 365 blocked

Exchange Online, SharePoint Online, Teams, Graph and the admin portals. A session is the only path to APM data from a personal device.

Permitted pathSession boundary controlDenied path

Conditional Access decides whether a session may be established; it does not decide what may leave one. The two application groups are the egress boundary. The block on the unmanaged path depends on three tenant policies that are currently report-only and one enforced policy that currently permits unmanaged browser access to all applications; each is named with the change required in section 7.
