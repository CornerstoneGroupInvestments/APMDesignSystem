Sequencing & dependencies

The schedule is gated by APM dependencies — not by our delivery capacity.

Delivery is a tight, AI-assisted two-person team (Shaun Struik on design/DDDs/documentation/KB + identity & the Function App, and the AVD Build Engineer on the hands-on AVD / Nerdio / Intune / image build) — efficient and on track. The real risk to 30 Sep is APM-side dependencies: APM is running several tier-one projects at once, so network build, decisions, approvals and pen-test scheduling sit with APM departments. The panel below tracks those dependencies; the findings call out what is gating progress now.

JOB SEEKER — GATING DEPENDENCIES (in order)
●Code-signing certificate is the master gate (D-14). One fleet-trusted cert — added by APM Cyber as a WDAC allowed signer (D-7) — unblocks the entire device-side credential pipeline (token fetch, lock-screen render, LSA write) and Nerdio session-host script signing at once. Sits with APM.
●Network design must be finalised & approved by APM before any networking or credential-pipeline deploys — the public-endpoint workaround was rejected. The live build is running in the FVE (test), not prod.
●Job Seeker built work is real but gated. Golden image captured (WDAC-hardened); CA set built but report-only until cyber re-approves; AVD is definitions/logic only until network lands; credential pipeline blocked pending the cert + network.
●Credential Proxy public ingress (D-3) is the single biggest unverified link — no site→Azure private path exists, so remote kiosks need a hardened EasyAuth-protected public ingress.
●Pen test gates go-live. Design update + re-CAB, then penetration test and remediation must clear before rollout.
Recommendation to the Portfolio Manager:
  1. Critical chain: Job Seeker (Intune → Nerdio/autoscale → Function App → design update → pen test) → Standard User. Both depend on the Network Team delivering the Azure spoke (N7) on time — that hand-off is the #1 external dependency.
  2. Lock the APM dependencies — confirm an APM owner and date for the prod network, DR-010/011 decisions, the pen-test vendor/windows, and the Developer (PDE) owner. These, not delivery throughput, decide the 30 Sep outcome.
  3. Four of five use cases complete inside the contract — Network, Job Seeker, Standard User (whole workstream design→GA, 13 Jul–14 Aug), ES and Privileged (17 Aug–28 Sep) all land by 30 Sep. Developer is the exception: with one build engineer the workstreams run one after another (Standard → Privileged → Developer), so Developer cannot start until Privileged finishes (28 Sep) and GA lands ~20 Nov, past contract end. Pulling it inside 30 Sep needs a second build engineer from mid-Aug, otherwise confirm APM accepts Developer GA post-contract. Watch the Standard User window — image complete ~2 Aug then pilot, pen-test, remediation and rollout all inside ~12 days; pre-book the pen-test. Job Seeker rollout stays split: Phase 1 (~360 of 540) end Aug, Phase 2 (~180) in Sep, dependent on old-device returns + condition.
  4. Close the gating decisions now: Job Seeker code-signing cert (D-14) + WDAC allowed-signer rule (D-7) + network-design approval + Credential Proxy ingress (D-3); SU printing (DR-010) & mapped drive (DR-011); confirm Nerdio is live; nominate the Developer (PDE) owner.
